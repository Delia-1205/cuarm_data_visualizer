返回可视化

两种日志格式

可视化器会按列数自动选用 schema（侧边栏显示 schema=telemetry 或 rt_control）：

来源典型列数（双臂 [7,2,7]）定义文件
遥测 telemetry / CTLG .bin / writeToLogFile依结构（如 6 关节 ≈155）log_schema.json
rt_control 文本 write_data_task439（含 task/line 三组×6）；旧文件无 task 块为 385log_schema_rt_control.json

下列 Meta / 关节 / 任务 分节默认描述 遥测。rt_control 专用列见下文 「rt_control 文本日志」。

时间轴

默认用 Meta.running_cost（控制周期耗时，单位 微秒）做累积：

  • t[0] = 0
  • t[r] = t[r-1] + running_cost[r-1] × 10⁻⁶（秒）

周期抖动、过载拖长都会反映在横轴上。在左侧填写 sample_time 并点击「应用结构并重新解析」后，改为固定步长。清空后再点应用，或重新打开 TXT，回到 running_cost。没有有效 running_cost 且未指定采样时间时用行号。

单位

非力矩模式时，角度相关量写成 度；力矩模式保持原单位。*_cost 为微秒。tool_pose 的 xyz 是米、姿态是四元数。笛卡尔 rx/ry/rz 为旋转向量（非力矩时转成度）。

Meta（整机）

字段含义
running_cost整圈控制周期墙钟时间（含 sleep），微秒；也用于时间轴
robotics_total_cost规划 / 运动学这一段耗时
hardware_communication_cost从周期开始到硬件读写结束
communication_cost到发完状态、入日志队列为止（sleep 前）
motor_communication_cost电机总线读写耗时
gripper_communication_cost夹爪通信耗时
button_communication_cost按钮通信耗时
actuator_mode下发给驱动器的模式：0 位置 / 1 速度 / 2 力矩
control_strategy规划策略：0 关节 / 1 笛卡尔 / 2 直线 / 3 零空间 / 4 重力补偿 / 5 示教 / 6 回放
branch_state本周期主循环分支（故障、恢复、新指令、无客户端等）
system_state1 启动 / 2 空闲 / 3 运动 / 4 到位收敛 / 5 错误 / 6 恢复 / 7 关机 / 8 离线
plan_result0 成功 / 1 位姿不可达 / 2 直线路径失败
system_diagnostic_flags系统诊断位掩码（限位、饱和、跟踪失败、碰撞等）
button_state物理按钮状态
simulation1 不把命令真正发给硬件
target_type上层目标类型：位置 / 速度 / 力矩（决定 PID 怎么算）

每关节：指令链路

用户目标
  → target_before_interpolation   插值前的关节目标
  → sliced_tar                    插值后、本周期要跟的目标
  → pid_cmd                       按「目标类型 × 执行器模式」算出的命令
  → guard_pos_cmd                 关节限位保护后
  → sat_cmd                       软限位饱和后
  → jump_cmd                      限制单步跳变后
  → motor_target                  最终下发给电机的命令
字段含义
motor_target本周期发给硬件的最终命令
joint_position / velocity / acceleration规划器侧关节状态（srv_state）
joint_torque规划器侧关节力矩
motor_position / velocity / torque硬件读回来的关节量（robot_state）
pid_cmd位置跟位置直接透传；位置跟速度是 Kp*(tar-x)；力矩环再加阻尼等
guard_pos_cmd速度/力矩模式下，防止下一拍冲出位置限位
sat_cmd按软限位把命令夹到合法范围
jump_cmd限制相邻周期命令跳变
joint_gravity逆动力学算出的重力矩
friction摩擦补偿（库仑 + 粘滞，用滤波速度）
gravity_kd_effect重力环阻尼项（当前代码里常为 0）
filtered_joint_vel低通 + 死区后的关节速度，给摩擦模型用
arm_diagnostic_flags该关节诊断位（硬限位、跟踪失败等）

对比跟踪：sliced_tar vs joint_position。对比下发是否被削：pid_cmd → sat_cmd → jump_cmd → motor_target。

末端 / 任务空间（每臂固定列）

字段含义
tool_pose_{x,y,z,qw,qx,qy,qz}工具位姿：米 + 四元数
task_target_before_interpolation_*笛卡尔目标，插值前
task_sliced_tar_*笛卡尔插值后的本周期目标
task_pose_*当前任务空间位姿（旋转向量）

关节空间看 sliced_tar，笛卡尔/直线看 task_sliced_tar。

夹爪（有夹爪才写）

字段含义
gripper_target夹爪目标
gripper_position夹爪实际位置
gripper_diagnostic_flags夹爪诊断位

rt_control 文本日志（write_data_task）

由 cuarm_rt_control/example/rt_control.cpp 写盘，无表头、无 wall-clock 时间戳；横轴仍用 Meta.running_cost 累积。与遥测相比：不含 pid_cmd / guard_pos_cmd / sat_cmd / jump_cmd / arm_diagnostic_flags 等列；Meta 为耗时拆分 + 模式枚举，不是 system_state 那一套。

Meta（12 列，顺序固定）

字段含义
running_cost整圈控制周期墙钟时间（含 sleep），微秒；时间轴来源
robotics_total_cost规划器 update 总耗时（含下列子项）
communication_cost到本周期状态打包、入写盘队列前（sleep 前）
hardware_communication_cost本周期硬件读写段耗时
robotics_setup_cost规划器 setup 段（指令解析、插值改参等）
robotics_Null_cost零空间相关耗时
robotics_FK_cost正向运动学
robotics_IK_cost逆运动学（Task / MoveL 常见非零）
robotics_ID_cost逆动力学（重力等）
robotics_simulation_addition_cost仿真附加计算
command_mode执行器模式：0 位置 / 1 速度 / 2 力矩（影响角度是否写成度）
motion_type运动类型：0 关节 MoveJ / 1 Null / 2 Task / 3 Motor / 4 MoveL（直线）/ 5 力控算法 / 6–8 Jog / 9 回放

诊断 J/L 切换：看 motion_type 跳变 alongside robotics_IK_cost、关节 sliced_tar vs task_sliced_tar_*。

每臂列顺序（写盘 / 字段树一致）

  1. 每关节 8 列交错：sliced_tar → motor_target → joint_position → joint_velocity → joint_acceleration → motor_position → motor_velocity → motor_torque
  2. tool_pose 7 列：x,y,z（m）+ qw,qx,qy,qz
  3. 每关节 target_before_interpolation
  4. （439 列版本） 固定 6 列 ×3：task_target_before_interpolation、task_sliced_tar、task_pose（各 x,y,z,rx,ry,rz）
  5. 每关节 motor_raw_position、joint_gravity、gravity、sat_motor_cmd、joint_impedance、impedance、joint_torque、torque_sensor_raw、torque_sensor、encoder_sensor_raw、friction、gravity_kd_effect、filtered_joint_vel

sliced_tar：插值后本周期关节目标（规划器 interpolated_target）。motor_target：下发驱动的最终命令。对比跟踪：sliced_tar vs joint_position（规划器状态）或 motor_position（硬件反馈）。

task / 直线（MoveL）三组 6 维

前缀含义
task_target_before_interpolation_{x,y,z,rx,ry,rz}本周期 Task 插值前目标：平移 m；姿态 rx,ry,rz 在日志里为度（与 motion_type 为 Task / TaskLine 时写入）
task_sliced_tar_{x,y,z,rx,ry,rz}Task 空间插值后目标（task_interpolated_target）；仅在 motion_type = MoveL (4) 时更新，MoveJ 时多为 0
task_pose_{x,y,z,rx,ry,rz}当前任务空间位姿（FK / 任务表示）；平移 m，姿态为度

MoveL 段优先看 task_sliced_tar 与 tool_pose；MoveJ 段看关节 sliced_tar。385 列旧日志无上述三组，可视化器自动用 legacy schema。

其他每关节量（rt_control）

字段含义
joint_gravity / gravity关节空间 / 电机侧重力补偿输出
sat_motor_cmd软限位饱和后的电机命令（规划器 sat_motor_cmd_）
joint_impedance / impedance关节 / 电机侧阻抗控制相关量
torque_sensor_raw / torque_sensor力矩传感器原始 / 处理后
encoder_sensor_raw / motor_raw_position列在 schema 中保留；当前 rt_control 写盘路径可能未填充，曲线常为 0
friction / filtered_joint_vel / gravity_kd_effect摩擦补偿、滤波关节速度、重力环阻尼项

夹爪（rt_control，有夹爪才写）

字段含义
gripper_command面板下发的夹爪关节命令
gripper_act_set_command驱动器实际 set 值
gripper_position夹爪关节反馈位置
